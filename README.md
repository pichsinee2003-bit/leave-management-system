
🏢 Leave Management System (ระบบบริหารจัดการการลางานองค์กร)
ระบบบริหารจัดการการลางานแบบครบวงจร พัฒนาด้วย Python (Flask) และ Bootstrap 5 รองรับการบริหารจัดการสำหรับกลุ่มบริษัทขนาดใหญ่ (Multi-Company) พร้อมระบบคำนวณวันลาอัตโนมัติ การตรวจสอบวันลาทับซ้อน การเช็คอัตรากำลังพลในแผนก และระบบจำลองการแจ้งเตือนผ่านอีเมล

✨ ฟีเจอร์เด่นของระบบ (Key Features)
1. ระบบจัดการหลายบริษัท (Multi-Company Support)
รองรับการบริหารจัดการพนักงานและผู้อนุมัติแยกตามกลุ่มบริษัทสูงสุด 5 บริษัท

2. ระบบสิทธิ์ผู้ใช้งาน 2 ระดับ (Dual Role System)
พนักงาน (Employee):

ยื่นคำขอลางาน (รองรับทั้งแบบเต็มวัน และครึ่งวัน ช่วงเช้า/บ่าย)

แนบไฟล์เอกสารประกอบ (รูปภาพ / PDF) พร้อมระบบดูตัวอย่างไฟล์แนบ (Preview Modal)

ตรวจสอบโควตาวันลาคงเหลือและประวัติสถานะการลาของตนเอง

ยกเลิกคำขอลาได้เฉพาะกรณีที่สถานะยังเป็น "รออนุมัติ"

ผู้อนุมัติ / HR Admin (Approver):

ตรวจสอบ อนุมัติ (Approve) หรือปฏิเสธ (Reject) คำขอลางานพร้อมระบุเหตุผล

จัดการบัญชีพนักงาน (เพิ่มพนักงานใหม่, แก้ไขโควตาวันลา, เปลี่ยนรหัสผ่าน, ลบพนักงาน)

ตั้งค่าประเภทการลาเพิ่มเติมในระบบได้

ระบบตั้งค่าผู้อนุมัติสำรอง (Delegate Approver) ในช่วงที่ผู้จัดการลาพักร้อน

3. ระบบอัจฉริยะและการแจ้งเตือน (Smart Features)
Smart Leave Calculation: ระบบคำนวณวันลาอัตโนมัติ โดยหักวันอาทิตย์และวันหยุดนักขัตฤกษ์ของไทยให้อัตโนมัติ

Overlap Check: ป้องกันการยื่นใบลาทับซ้อนกับช่วงเวลาที่เคยขอไว้แล้วของพนักงาน

Team Capacity Check (>50% Warning): ระบบตรวจสอบอัตรากำลังพล หากในแผนกมีพนักงานลาในช่วงเวลาเดียวกันเกิน 50% ระบบจะแจ้งเตือน (Smart Warning Modal) เพื่อป้องกันผลกระทบต่อการปฏิบัติงานของทีม

Team Leave Calendar: ปฏิทินแสดงภาพรวมวันลาของเพื่อนร่วมทีมในรูปแบบรายเดือน

Email Simulation: จำลองการส่งอีเมลแจ้งเตือนผลการพิจารณา (อนุมัติ/ไม่อนุมัติ) ไปยังพนักงานอัตโนมัติ

🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
Backend: Python, Flask

Frontend: HTML5, CSS3, Bootstrap 5, Bootstrap Icons, Google Fonts (Sarabun)

Storage: Client-side LocalStorage (จำลองฐานข้อมูลในระดับ Frontend เพื่อความสะดวกรวดเร็วในการทดสอบ)

🚀 วิธีการติดตั้งและรันโปรเจค (Getting Started)
ติดตั้ง Python บนเครื่องของคุณ (แนะนำเวอร์ชัน 3.8 ขึ้นไป)

ติดตั้งไลบรารี Flask ผ่าน Terminal / Command Prompt:

Bash
pip install flask
ดาวน์โหลดหรือสร้างไฟล์โค้ดโปรเจค (เช่น app.py)

รันโปรแกรมด้วยคำสั่ง:

Bash
python app.py
เปิดเว็บเบราว์เซอร์แล้วเข้าสู่เว็บไซต์ผ่านลิงก์:
[http://127.0.0.1:5000](http://127.0.0.1:5000)
