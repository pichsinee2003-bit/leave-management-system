# Enterprise Leave Management System

A comprehensive Flask-based leave management application featuring multi-company support, team calendar visualization, smart capacity warning (>50% overlap), delegate approver system, and email notification simulation.

## Project Structure
- `app.py`: Main Flask application backend and API routes.
- `utils.py`: Python module containing backend logic and metadata handlers.
- `templates/index.html`: Frontend user interface built with Bootstrap 5.
- `requirements.txt`: Project dependency configuration.
